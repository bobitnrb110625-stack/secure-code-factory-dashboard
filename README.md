# Secure Code Factory Monitoring Dashboard

## Project Overview
This project aims to develop a secure dashboard for monitoring and reporting security findings across the Software Development Life Cycle (SDLC) infrastructure.

## Technologies
- Python
- Django
- Matplotlib
- HTML and CSS
- GitHub
- Trello

## SDLC Components
1. Endpoint/IDE
2. Version Control System (VCS)
3. CI/CD
4. Container Registry
5. Production

## Project Scope
The prototype will allow authorized users to record, classify, monitor, and report security findings using manually entered or sample data.

## User Roles
- Security Analyst
- Administrator

Part 1 report uploaded. Development of the prototype is planned next.
